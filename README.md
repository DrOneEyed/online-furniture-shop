# Online Furniture Shop

A full-stack PHP e-commerce platform for an online furniture store, featuring product browsing, shopping cart, checkout, and an admin management panel backed by MySQL.

## Features

- Product catalogue with categories and search
- Individual product detail pages with images
- Shopping cart with quantity management
- Secure checkout and order processing
- Admin dashboard for product and order management
- User authentication and account management

## Getting Started

```bash
git clone https://github.com/DrOneEyed/online-furniture-shop.git
cd online-furniture-shop
```

1. Import the SQL schema from `SQL File/` into MySQL
2. Configure DB credentials
3. Serve with Apache/XAMPP or PHP built-in server:

```bash
php -S localhost:8000
```
